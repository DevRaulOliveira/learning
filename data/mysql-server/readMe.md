# SQL SERVER
![image](https://github.com/user-attachments/assets/86a816f7-9464-4778-97e6-a3d36afe8ff5)

O banco de dados *SQL-SERVER* é um banco de dados relacional, serviço de gerenciamento de banco de dados relacional criado pela empresa *Sybase* em parceria com a *Microsoft* nos anos 80, tendo o lançamento do produto no ano de 1989. Atualmente o serviço é mantido pela Microsoft, que recebeu diversas atualizações significativas ao longo dos anos, sendo a ultima de maior relevancia a incorporação junto ao Microsoft Azure em 2010.

# Informações gerais
O banco de dados SQL-SERVER é um sistema de estruturação de dados em formato de tabela, criado nos anos 70.

# Detalhes técnicos do SQL-SERVER
## Incompatibilidades
- Não tem compatibilidade com o comando **REPLACE** sendo assim, sempre que deseja substituir algo é preciso realizar o processo de *DROP* e *CREATE*.
